# EXP-003 — scaffolds

Deterministic lexical scaffolds for the pilot story, generated by
`scripts/build_exp003_scaffold.py`:

- `<story_id>/scaffold.json` — machine-readable scaffold: token-aligned
  candidates with full provenance (layer / source / kind / detail),
  resource pins (dictionary, lexicon, alternative resources, curation
  tables), and generation statistics.
- `<story_id>/scaffold_B.txt` / `_C.txt` / `_D.txt` — the rendered scaffold
  blocks embedded into the operator prompts for conditions B, C and D.

These files embed the aligned Polish token stream of the copyrighted story
and are **gitignored** — they stay local. Regenerate deterministically with:

```bash
python scripts/build_exp003_scaffold.py build --force
```

Regeneration is byte-identical (except the documented `generator.commit`
field, which is repo state). See `curation/` for the committed per-story
curation tables that drive alignment, and `DESIGN.md` §6/§7 for the
alignment and provenance policy.
